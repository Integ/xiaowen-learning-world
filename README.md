# 小文认知世界

一个面向 2–5 岁学龄前儿童的无文字语言启蒙小游戏。孩子通过大图案、中文语音、动画、音效和即时奖励认识家里的物品与家庭成员。

## 设计原则

- 每个游戏画面只展示三个可操作物体
- 不依赖文字阅读，所有关键提示由图案、动作和语音完成
- 自由探索后自动进入“听音找物”小游戏
- 每次点击都有动画、音效或语音反馈
- 支持触屏、键盘、横屏和竖屏
- 背景音乐由浏览器实时合成，不加载外部音乐文件

## 正反馈机制

- 每次答对后播放一段短小、明亮的奖励旋律
- 连续答对 3 个问题后播放更完整的庆祝音乐
- 连胜庆祝时展示小熊鼓掌、皇冠、三颗星和彩纸动画
- 答错后连胜重新计算，但不会扣除已经获得的星星
- 奖励音乐使用 Web Audio API 实时合成，动画使用 CSS 与 Canvas 绘制，不依赖第三方素材或额外授权文件
